# Black Hills IP Architecture Diagrams

This repository is a collection of diagrams representing the complete Black Hills system. The diagrams are created using **Mermaid.js** syntax, a powerful and flexible tool for visualizing complex systems.

## Diagram Types

The repository will include various types of diagrams, such as:

- **Architecture Diagrams**: High-level overviews of system components and their interactions.
- **Sequence Diagrams**: Detailed representations of processes and workflows within the system.

## Purpose

These diagrams aim to provide a clear and concise understanding of the Black Hills system, making it easier for developers, architects, and stakeholders to collaborate and maintain the system effectively.

## Tools and Requirements

To view or edit the diagrams, you will need:

- A Markdown editor or viewer that supports Mermaid.js rendering.
- Familiarity with Mermaid.js syntax for creating or modifying diagrams.
- For a better experience in **Visual Studio Code**, consider installing the extension [Markdown Preview Mermaid Support](https://marketplace.visualstudio.com/items?itemName=bierner.markdown-mermaid) to enable rendering of Mermaid.js diagrams directly in the Markdown preview.

Feel free to contribute by adding new diagrams or improving existing ones!
